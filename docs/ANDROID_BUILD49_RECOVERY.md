# Android 0.7.9 build49

从 Android build43 的 Git 提交恢复开发分支，并对照 build45 至 build49 的现存测试包重建变更。原 build49 提交未找回。

- 图片预览默认按屏幕高度显示，保留缩放和局部高清解码。同分类左右翻图，跨分类上下切换。
- 底部从左侧提供备注、锁定和置顶，右侧提供复制。系统剪贴板中的首个条目仍是当前图片时，复制入口禁用。成功复制时显示反馈。
- 悬浮面板的清除和删除使用按压反馈。第四个及以后的分类选中后向中间滚动。
- 关于页提供检查更新、启动时检查更新、权限声明和开源许可。返回按页面层级回退。Android 更新客户端使用现有签名的公开更新源。
- 悬浮窗检查系统窗口是否实际挂载，在正常任务清理和解锁后恢复。闲置时释放面板视图和缩略图，共享无待发送数据时延长维护间隔。
