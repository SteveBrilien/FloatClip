# FloatClip 0.7.8 / build 25 候选

公共更新仍为 0.7.1。本轮不将未经用户检查的候选提升到公共清单，也不复用旧下载地址覆盖安装包。

## 差异及最小修改

先读唯一设计规范、变更记录、共享资源及目标页面。确认分类只有一个输入框、复制后的刷新抢在动画前重建卡片、ListViewItem 仍继承 Aero 模板、手机文件页采用大面积填色按钮。复用现有 WPF UI、MVVM、共享协议及原有图片加密存储，先改组件再接业务页面，未增加第三方 UI 框架。

- Windows 右键“分类”展示已有分类；选择/新建通过 ViewModel 和独立服务保存。设置内每个分类选择语义特征色，卡片显示小色标，名称仍使用原 vault 字段。
- 成功复制后显示“已复制”；按压使用统一 Scale/EaseOut 和 Pressed 色。短暂合并界面刷新，让释放动画完成；实际收录/同步服务没有延后。640 ms 提示计时与减少动画独立，快速复制替换上次状态。
- 文件行使用共享纯色 Border/GridViewRowPresenter，保留列宽、多选、键盘焦点和可访问名称，去掉系统默认渐变层。
- 剪贴板背景增加纯色/磨砂/透明；只有背景使用不透明度，卡片和文字保持清晰。Windows 11 的 DWM Acrylic 使用既有 WPF UI API；透明模式用 WPF per-pixel 窗口，需要重新打开应用，设置中已明确标注。文件和设置仍为纯色。系统关闭透明、High Contrast 或 DWM 不可用时回退纯色。没有增加点击穿透。
- Android 文件页使用共享色彩/尺寸与 Ripple 反馈，头部、筛选、选择操作及详情操作使用紧凑布局，卡片仍为 12 dp，保留滑动和长按多选、进度及文件夹授权流程。
- Android 新增主动选图/截图分享入口，读取授权的 content URI，归一化为 PNG 后复用加密图片库；不扫描相册。截图若未被系统复制到 ClipData，不会凭截图动作自动进入历史，可从系统“分享 → FloatClip 剪贴板”或应用内图片入口加入。
- 蓝牙/FCP3 仅文字，FCP4 局域网才支持文件目录。手机显示真实文件会话数；打开文件页重发本机清单。Windows 修复已有蓝牙会话阻止已授权 LAN 接续的问题。只有蓝牙授权且从未授权过 LAN 的设备仍须在设备页核对一次局域网连接。

## 用户检查

1. 覆盖安装匹配签名的 Android 候选；打开剪贴板点击图片入口，或从截图分享菜单选择 FloatClip。图片应进入本机历史，复制后其他支持图片的应用可粘贴。
2. 两端连接同一 Wi-Fi/手机热点，在设备页完成局域网授权。手机应显示“可接收文件”，然后添加文件，电脑无需先传内容即可看到目录项。仅有蓝牙文字连接时页面应明确提示。
3. Windows 右键记录选分类，在设置改特征色；点击文字时检查缩放及“已复制”；检查文件选中行是纯色。
4. 选择磨砂后回到剪贴板；透明需重新打开应用。检查导航、搜索、置顶、失焦收起、窗口拖动/缩放，密集文件页应保持纯色。
