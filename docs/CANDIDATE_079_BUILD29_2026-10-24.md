## 新发现并修复

1. 关闭自动连接时，复制图片无条件关闭已有会话，导致图片发不出去。两端保留正常会话，Windows 加入真实图片传输回归。
2. 主界面接收同步状态广播时会清空并重建列表，图片每次先空白再加载，造成反复闪动。内容未变化时保留 View 实例。
3. 导入按钮原来作为列表尾项随内容移动；主界面与悬浮窗都改为独立视口固定层。
4. 分类快速切到空列表时，旧动画回调可能把旧卡片放回来；清空先使旧代失效。
5. 图片缩略图在 UI 线程解密/解码；改为后台采样与缓存。长图裁剪不侵入说明区域。
6. Windows 全文窗口加了外层容器，旧测试错误强转 Content；改为查找实际 Emoji 文本控件。
7. UpdateChecks 把真实签名清单固定断言为 0.7.1；改为校验签名对应平台版本、build、URL、摘要与大小，而不是固定历史版本。
