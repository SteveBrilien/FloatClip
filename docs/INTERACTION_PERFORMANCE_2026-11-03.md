# FloatClip 0.7.9 build39：历史加载与交互

本轮在 build37 的配对、暂停共享、设备身份合并和重复复制排序修复上继续推进；保留 Windows WPF/XAML、Android 原生视图、原 vault/图片加密格式、包名、配对协议和原安装签名。

## 改动与入口

- Android 主历史从一次创建最多100张卡片改为有界 ListView，可滚动访问全部500条记录；悬浮列表继续复用该控件，按栏目保留滚动位置。
- 元数据按文件修订复用内存快照，保存后失效；图片原件独立加密存储。缩略图在后台解码，8 MB 内存缓存，独立加密的可清理磁盘缓存最多96项/32 MB；删除缓存不影响原件。长图卡片只采样顶部区域，大图预览有独立队列。
- 当前可见图片优先，分离大图队列；分离失效回调，卡片移除后取消加载。闲置约200 ms后少量预取可能切换的来源/分类和下方图片，每批最多3张，队列有上限，避免预取全部历史。
- Windows 栏目切换复用元数据，首批12张卡片，接近底部再加载12张；图片读取/解码移到两个后台任务，取消过时请求。缩略图双边均不超过400像素，最多24项，避免超长图按宽度缩放占用大量内存。相邻来源少量闲置预取，最多2张。
- Windows 取消置顶后是普通非置顶窗口：失焦、复制结束不自动隐藏，可被其他窗口遮挡并从任务栏返回；Esc、关闭按钮和快捷键仍可主动收起。标题按钮使用共享 Hover/Pressed/Focus/Disabled 资源，关闭符号为红色、悬停红底。
- 手机“设置 → 外观”新增纯色、背景透明、雾化、整窗透明模式。滑条明确为不透明度：100%不透明；纯色模式不显示被覆盖的透明设置；卡片不透明度不再被来源底色开关静默覆盖。雾化目前是半透明表面混色，不声称具备系统跨窗口实时模糊。
- 手机“动画与交互”支持舒缓、利落、线性与四控制点贝塞尔曲线；打开/关闭、按压、开关使用相应曲线。打开/关闭的状态与输入先提交，收回立即恢复悬浮球，旧动画结束不能隐藏新打开面板。0 ms明确关闭动画。
- “滑条范围”可修改五种交互参数的上下限。缩放在10–120%内、时长在0–5000 ms内自定；数值可点击直接输入。恢复外观默认值会恢复曲线、范围和表面设置，不撤销服务授权。
- 状态栏/共享/更新通知统一使用透明底轮廓图标，避免启动图标被系统遮罩为方块。
- “启动时检查更新”默认关闭。开启后冷启动后台检查，失败或无新版保持安静；发现新版本显示通知及应用内下载入口，同一通道版本只提醒一次。通知点击后重新验签检查，不信任 Intent 中的下载信息。原下载器继续验证大小、SHA-256、包名、版本和证书，随后请求未知应用安装权限并交由系统安装器确认。

## build38 撤回

Windows CI在冷启动时发现异步缩略图跨线程更新控件，尚未进入原生断言即退出。该候选未作为正式更新推广；修复为明确 Dispatcher 派送后升 build39，两端统一重建。build38 的MCP临时候选发布已撤回，不能将其编译通过写成原生检查通过。
