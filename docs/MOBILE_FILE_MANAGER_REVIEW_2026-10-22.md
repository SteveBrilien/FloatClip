# 手机文件管理交互修订（2026-10-22）

> 2026-10-23 更新：用户随后授权制作两端候选，Android 原生 12dp 卡片、滑动、多选和文件管理已接入。下文保留预览阶段记录；实现与验证边界见 [候选交接](CANDIDATE_0.7.6_2026-10-23.md)。

本轮按用户最新三张参考图修订手机文件页交互预览。Windows 仍使用资源管理器式列表，手机使用文件卡片。此前“每张卡片下都放下载 / 另存为 / 更多，来源与时间放卡片外”的手机方案已被本轮取代。

对话预览：floatclip-mobile-file-manager.html；旧 floatclip-mobile-file-cards.html 为上轮方案。本轮没有修改 Android 客户端、配对协议、线上版本或安装包。

## 已实现的可体验交互

- 卡片常态仅显示文件名、大小、右侧文件类型图标，以及区块内的来源 / 共享时间。去掉每张卡片常驻的操作栏和卡片外重复的时间来源行。长文件名两行省略，详情保留全名。
- 左上角状态角标使用云下载 / 下载中 / 已下载 / 离线 / 保留图标，不依赖单独颜色。类型图标以本机可用状态显示虚线或实心；保留状态可在详情切换。
- 实际指针手势：向左移动超过 45px 且以水平方向为主才露出下载 / 分享；向右关闭。普通点击进入详情，已展开时点击先收起。长按 500ms 进入多选，移动超过 9px 取消长按识别，避免与滚动冲突。
- 多选时整个卡片可切换选择，也可点复选框；支持当前时间范围全选 / 取消全选。头部“选择”提供不依赖长按的入口。键盘左箭头展开操作，Shift+F10 或右键进入选择，Escape 退出；日期筛选变化会重置选择，避免意外处理隐藏文件。
- 详情页包含下载 / 保存到、分享、预览、保留，以及完整属性。预览未下载文件不会静默开始下载。用户加入的真实本地文件仅读元信息，不伪造正文解析。
- 批量下载先选择文件夹；对已在本机的文件保存副本，不重复模拟网络下载。任务卡片显示当前就绪数量、各文件状态、总字节进度、百分比和按采样吞吐估算的剩余时间。离线文件存在时显示剩余时间未知，不倒数虚构的完成时刻。
- 分享时冻结所选文件集合，先准备所有未下载文件，全部就绪后自动显示系统分享面板示意。目标应用交接后仅说明交接动作，不显示“发送成功”。出现离线项时停止在任务卡片，必须明确选择仅处理可用文件才允许部分分享，不能静默少发。
- 任务可取消，已完成的缓存保留，未完成文件不标记可用；任务进度更新不会不断替换取消按钮，保留键盘焦点。弹出卡片使背景暂不可操作，限制 Tab 焦点，并可关闭 / Escape。
- 时间筛选按**共享时间**：全部、今天、近 7 天、近 30 天、自定义起止，拒绝倒置区间。原始修改 / 创建 / 下载时间独立存放，不混用。
- 文件管理区分“清理下载缓存”和“清空文件记录”，作用于当前共享时间范围，清理前显示数量 / 大小。默认保留已标记文件；不删除来源设备文件和另存副本。移除记录可选择是否同时清缓存；单独缓存索引保留无记录的下载项，使之后仍可清理孤立缓存。加入的本机原文件从不作为下载缓存删除。

## Android 实装交接要点

用户此前限定本会话负责 Windows 开发。本轮手机部分是确认跨端设计的预览，不意味着 Android 已实现下述能力。确认交互后应把这些约束交给负责 Android 的工作，不直接覆盖其未提交改动。

1. 使用稳定目录 ID / 文件版本 / 来源标识分离元信息、可用状态、私有下载缓存、外部保存副本和任务；列表与任务需要落库，源文件撤回 / 修改与权限失效要正确回退状态。与 Windows 的持久目录 / 拉取协议仍需能力协商，不能假设旧主动文件邀请已经等价支持。
2. 文件下载完成并校验后才标记可用；批量任务保留逐项结果，失败重试不得重复复制成功项或默默改变集合。取消删除临时文件，保留已完成项。进度基于真实字节，速率可做滑动平均；停滞 / 离线不显示确定 ETA，复制到外部目录的阶段也要单独反馈。
3. 指定目录使用 Storage Access Framework 的 ACTION_OPEN_DOCUMENT_TREE；按系统授予的标志保留可持久 URI 权限，逐文件写入。权限失效或写入失败要停在可恢复状态，不能显示保存成功。[Android 官方文件与目录访问](https://developer.android.com/training/data-storage/shared/documents-files)
4. 单文件分享 ACTION_SEND，多文件 ACTION_SEND_MULTIPLE，传递可访问的 content URI，通过 FileProvider 等提供临时只读授权，使用系统 chooser。不要把本轮固定的微信 / QQ / 邮件演示选项直接写成产品自制应用列表；实际目标由系统及 MIME 能力决定，混合格式可能不被某些目标接收。交接不等于目标应用已发送。[Android 官方跨应用分享](https://developer.android.com/develop/ui/compose/sharing/send)
5. UI 展示下载准备卡片；全部文件就绪后只在界面处于可交互状态时打开系统分享，后台完成则通过可恢复入口继续，避免违反系统后台启动限制。具体机型与系统版本须实测。该项是实现建议，尚未验证 Android 后台行为。
6. 原生手机选择操作栏应在安全区内保持可达；滑动和长按配合滚动判定、触觉反馈与可访问性操作；48dp 点击热区独立于小图标的视觉尺寸。删除操作不得跟随任意系统路径或误删用户源文件。
