## 本次实现

- 修复原生复制回写：从远端条目复制或粘贴不会新生一条“本机”记录；Android 使用每次写入标记，Windows 使用自有格式与系统剪贴板序号，其他应用重新复制相同文字仍可收录。0.7.1 替代本轮验证中的 0.7.0 候选。

- Android / Windows 默认进入本机剪贴板，移除常驻底部导航、发送编辑器和启动登录墙。设备与设置为次级入口。iPad / 跨网通道仍可经已认证的网页入口与同一个原生数据桥接入。
- 正文左对齐、垂直居中；来源不再占一行，只在角落保留轻量图标，设备名称移到筛选与条目操作。正文 16，功能图标 24，点击范围至少 44，主要按钮为 48。
- 搜索实时过滤内容、分类与来源，清空后恢复结果；Android 输入时只更新列表，保留输入框与焦点。
- 左滑只展开置顶 / 删除，右滑或点其他区域收回，删除可撤销，不自动执行破坏性整行滑动。单击不会置顶；按下缩小到约 98%，系统减少动画时关闭动效。
- Windows 新增系统剪贴板事件收录、托盘与快捷键，不以轮询维持运行；可暂停收录。iPad 仍是前台点按加入与复制。
- 浅色、深色、跟随系统均保留；平台来源特征色与半透明浅色块为可选项。图标沿用 0.4.0。

## 批判与未完成项

1. Android 11 仍受系统剪贴板读取限制；本次没有用悬浮窗或无障碍权限宣称已完成全天后台采集。未验证受控桥之前，只保证已授权且可读取时收录。
2. 原生局域网与网页通道仍是前台会话，长期自动重连、低功耗后台常驻和统一跨通道设备身份尚未完成。两种通道不能被宣传成同一条永久连接。
3. 局域网收到的文字写入同一历史，但尚不能将手动共享等同于自动剪贴板接续。后台连续复制、并发复制与断线恢复仍按产品方案继续验收。
4. iPad PWA 没有系统浮窗与后台监听能力。原生端跨网入口保留网页认证；本机与原生 LAN 不要求登录。
5. 原生局域网配对 / 文件页面仍复用前台传输组件，尚需进一步收敛为设备管理流程，不能以增加功能入口作为产品验收。
