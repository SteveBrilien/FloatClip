# FloatClip Web 0.1.0：iPad PWA 验证版

日期：2026-10-19（Asia/Shanghai）。试用入口：https://floatclip-share.zanycoot1.chatgpt.site 。网站保持私有，两端以同一所有者的 ChatGPT 账号登录。iPad 使用 Safari，Android 使用 Chrome；页面可添加到主屏幕，无需购买苹果开发者会员。

PWA 新增独立 WebRTC DataChannel 路径，不能直接访问原生版的自定义 TLS/TCP 协议。首版两端都使用网页，以最小安装门槛验证 iPad 体验。

普通 iPad Safari/PWA 不提供 Web Bluetooth；网页也不能直接建立 Wi-Fi Direct 组、切换系统 Wi-Fi 或自动开启热点。连接主力是现有 Wi-Fi，校园网隔离时由用户在手机系统中开启热点，让 iPad 加入。没有扫描或改动 OrangePi 测力设备 LAN。

## 使用流程

1. 两端先联网打开试用入口并登录；让它们连接同一可互通 Wi-Fi 或热点。
2. 一端设备页生成 8 位配对码，另一端在 2 分钟内输入。
3. 直连建立后核对两端 6 位证书识别码，分别确认，之后才允许共享内容。
4. 主动粘贴/发送文字，或选择文件。文件由对方先确认接收，SHA-256 校验成功后手动保存。
5. 保持两端前台；iPad Safari 分享菜单可“添加到主屏幕”。关闭页面前保存接收的文件。

初次加载与配对需要互联网。配对信息经过 HTTPS 服务；Cloudflare STUN 协助地址探测，可能看到连接来源地址，但不接收共享内容。文字和文件通过设备间 DTLS 加密 DataChannel 传输；没有配置 TURN，也不会自动切成云端文件中继。网络隔离、代理、mDNS 或 UDP 限制仍可能造成直连失败。

## 实现与边界

- 蓝白界面，支持浅色、深色、跟随系统；iPad/桌面宽屏侧栏，手机底部导航。外观、帮助、安装和隐私有详情页，编辑草稿跨页面保留。
- 短配对码有一次访客领取限制；令牌只保存哈希，不进入 URL。服务按所有者隔离房间，校验请求来源，限制创建、猜码与轮询频率。
- 房间 120 秒后逻辑失效，连接后尽力删除；遗留过期记录在后续创建请求中清理。服务端只存配对信息与限流状态，不接收文字或文件。
- 文字上限 64 KiB UTF-8，分片后确认送达；文件上限 64 MiB，16 KiB 分块、发送缓冲背压、默认限速 1 MiB/s，校验完成后才显示保存入口。
- 同时只允许一个文件，最近记录最多 8 项，最多保留一个已接收文件 Blob。共享内容只在当前页面内存，不自动打开文件、不自动读取剪贴板。
- 文件拒收、超限、未确认二进制、损坏校验和取消断开有处理；连接验证后最长 10 分钟。切后台/锁屏可能中断，不提供后台自动同步或断点续传。
- Service Worker 只缓存公共外壳资源和离线提示，不缓存配对 API、登录响应或共享内容；主文档不缓存。私有站点的 manifest 链接带 use-credentials，支持登录后获取安装清单。
