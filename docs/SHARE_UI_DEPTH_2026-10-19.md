# FloatClip Share 0.4.0：页面层级与紧凑布局

日期：2026-10-19（Asia/Shanghai）。独立共享预览包 `com.floatclip.probe`，版本 0.4.0-preview / build 8。

根据用户 14:35 的共享与设置截图调整原生 Android 页面。用户随后表示要拿走手机，因此本阶段停止远程 ADB、安装、截图和触控。以下新界面的验证只在构建主机执行。

## 页面结构

| 主入口 | 二级页面 | 继续进入 |
| --- | --- | --- |
| 共享 | 顶栏预览版 → 版本与更新；连接状态 → 设备主入口 | — |
| 设备 | 设备授权、连接帮助 | 连接帮助 → 网络与备用连接 → 原连接诊断 |
| 设置 | 外观、接收缓存、版本与更新、共享说明、连接帮助 | 连接帮助 → 网络与备用连接 |

主入口保留底部导航；详情页收起底栏，用顶栏返回和系统返回逐层退出。切换标签或进入详情时收起键盘；进入详情时记录来源与滚动位置，主题切换仍留在外观页，文字草稿跨标签页与主题重建保留。连接状态更新不重置当前层级。

## 布局与交互

- 顶部用小图标、当前页标题和预览版入口，删除重复的大品牌标题、标语和巨型页标题。
- 共享页依次呈现连接摘要、文字编辑与发送、文件入口、最近共享。连接摘要直接进入设备页，文件入口直接打开系统选择器。
- 设置首页使用分组菜单行，并展示当前主题、缓存占用与版本；详细说明和操作放在各自二级页。
- 页面边距、卡片内边距与圆角统一 16 dp，卡片间距 12 dp；主要点击目标至少 48 dp。宽屏限制正文宽度，保留大字体自然换行。
- 底栏标签居中对齐图标。二级页使用明确的返回标题；轻量过渡尊重系统动画开关。
- 蓝白浅色、深色和跟随系统保留同一套布局。Android 11 的系统栏图标设置继续通过已接收 insets 的 View 执行，避免启动时提前读取 DecorView。

## 验证范围

Android 11 / SDK 30 的启动测试覆盖三种主题；导航测试覆盖设置返回、主题切换保留草稿、设备帮助的多层系统返回，以及缓存、更新、共享说明返回来源页。测试只调用 Activity.onCreate，不调用 onStart，不启动手机发现或剪贴板读取。

Android assemble / lint / unit test 全部通过：7 项 SDK 30 测试，0 失败；lint 0 错误、1 条 UnusedAttribute 提示（enableOnBackInvokedCallback 在 API 33 以下不使用，旧版依赖 onBackPressed，新版已有版本判断）。另有返回兼容覆盖声明、ARM 工具和 JVM 内存的构建提示，未影响成功。Windows 自包含 x64 打包成功，120 项 Java 与 119 项 C# 核心断言通过，ZIP CRC 正常。Windows 本轮只同步版本与下载元数据，桌面 UI 沿用上一版。未验收新 UI 的真机手势/三键区域、大字体、深色视觉，也未验收两端配对和 Clash TUN。

## 与启动修复的关系

0.3.1 的 Android 11 闪退已经通过实际崩溃日志定位为窗口创建顺序问题。0.3.2 热修复已在用户 V2115A / Android 11 启动并打开设置，用户截图与之对应。0.4.0 保留该修复，但用户拿走手机后的新层级界面没有再远程安装。原 FloatClip 应用及其六个既有未提交文件保持不变。
