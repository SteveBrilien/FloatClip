# FloatClip Share P1 — 前台共享与蓝白界面

用户已批准继续开发、封装功能，主色蓝/白，浅色、深色、跟随系统。

本轮交付 Android 与 Windows 的独立共享预览版，沿用 com.floatclip.probe 独立签名升级；旧 FloatClip 正式包、悬浮球和六个未提交 UI 文件保持原哈希。P0 诊断保留独立入口。

## 功能边界

- 抽离不依赖 Android UI 的传输帧、会话、文本/文件状态；Android TLS 适配器和 Windows TLS 连接器独立。
- 现有用户网络中的 Android 监听 / Windows 连接；每次通过手机显示的高熵单次邀请授予一段临时会话，固定证书 SHA-256，TLS 1.2。邀请串合并地址/端口/指纹/秘密；不按 IP 持久信任设备。
- 用户主动粘贴/编辑后发送纯文本，UTF-8 最大 64 KiB，保留原始空白；接收后按需复制，不自动向其他应用输入。
- 普通单文件经系统选择器传入，先发清单、接收端确认后流式下载；SHA-256 完整校验后才显示完成，临时文件失败清理。初版上限 64 MiB，文件速率总预算 2 MiB/s，无自动打开或覆盖。
- Android 为前台会话；切后台结束，系统文件选择期间只保留有上限的会话。没有高频发现广播、永久唤醒锁、自动改网络、防火墙或代理。
- 暂不包含长期设备信任/撤销、自动剪贴板采集、后台常驻、续传、PC-PC 和 Wi-Fi Direct。界面不能把这些显示为已支持。
- OrangePi 有线口为测力设备专网：不扫描、探测、改路由，不作中继。实机验证继续使用 Windows ↔ 手机现有热点。

## 界面

三页：共享（发送编辑器、文件进度、收到的内容）、设备（临时连接/邀请/断开）、设置（跟随系统/浅色/深色）。详细技术诊断移入二级入口。
