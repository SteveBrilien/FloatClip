# FloatClip Share 0.3.1：手机端视觉规范与待验收清单

日期：2026-10-19（Asia/Shanghai）。版本 0.3.1-preview / build 5，独立包 com.floatclip.probe。

本轮按照用户要求，只修改源代码、离线检查并构建候选包。Windows 已关闭，没有连接 Windows、ADB 或手机，没有安装 APK，也没有进行真机视觉与两端传输测试。之前的完整应用配对超时仍未定位，本轮不宣称已修复。

## 实现范围

- 底部导航改为统一线性矢量图标、文字与浅蓝选中指示，去掉三个大号系统按钮。底栏使用白色/深色卡片表面，与系统导航区域连贯。
- Android 11 及以上显式处理系统栏、刘海和输入法边距。输入时隐藏应用底栏，把空间留给编辑区；较早版本保留系统窗口适配。实际手势/三键导航效果待验。
- 三页共用颜色、字体、卡片、圆角、按钮、分隔线和点击反馈。输入框具备聚焦描边，按钮去掉默认立体阴影和内缩，最小点击区域 48 dp。
- 主题选择改为带图标和选中状态的单选行。浅色、深色、跟随系统沿用同一布局；原生弹窗、光标、文字选区和下拉选择使用相应主题。
- 共享页收拢状态信息，突出文字发送，文件状态只在有内容时显示，统一空状态和历史操作。保留手动剪贴板访问与接收确认。
- 设备页保留附近发现主入口，把地址选择、备用邀请与旧诊断页收进连接帮助。记住设备与授权管理仍可访问。
- Windows 配套包同步颜色规范与 0.3.1 版本显示；两端在更新源构建号较低时不再显示旧版本下载入口。通信协议和连接路径不变。

## 明天建议按这个顺序验收

1. 安装 0.3.1 手机候选包；Windows 解压到单独目录，打开其中的 FloatClip.exe。两端设置页应显示 0.3.1。保留原日常使用目录。
2. 手机依次切换浅色、深色、跟随系统，查看共享、设备、设置、确认弹窗；检查底栏图标、选中态、系统三键/手势区域。输入一段生成文字，展开/收起键盘、切换页面、横屏和较大字体，检查遮挡、截断及草稿保留。
3. 让电脑连接手机热点或同一可互通 Wi-Fi，在 Windows 设备页查找手机。首次核对两端识别码，再检查记住设备后的重连。若失败，记录停在哪一步及错误信息，先不要同时修改多个网络设置。
4. 用测试文字与专用测试文件验证双向发送、接收确认、取消和另存。Clash TUN 保持日常状态先测；如失败，再由用户手动切换 TUN 对照。不要使用真实剪贴板或私人文件作为自动化测试输入。
5. 两端手动检查更新，确认通向各自平台的版本下载。新包属于共享预览通道，设备实测完成前不视为稳定版。

前台、发现窗口、会话期限和速率限制沿用上一版。没有改动 Clash、路由、DNS、防火墙、蓝牙或连接测力仪器的 LAN。原 FloatClip 六个既有未提交文件须继续保持基线哈希。
