# FloatClip 0.6.0：三端功能对齐与原版剪贴板整合

日期：2026-10-20（Asia/Shanghai）。本文件为实施前的范围与迁移约定。

## 范围

- 三端主导航统一为剪贴板、共享、设备、设置，保留蓝白 / 深色 / 跟随系统。
- 剪贴板记录保存在接收设备本地，按稳定来源设备 ID 分组；内容分类与来源设备分别筛选。支持搜索、置顶、复制、编辑分类、删除、备份导入导出和再次发送。
- Android 以 com.floatclip.app 原版为升级对象，保留 Android Keystore 加密库、悬浮球、无障碍粘贴、备份和原有本机管理页面。旧数据无来源时归为本机，迁移不删除源库。
- Android / Windows 通过受来源限制的原生宿主复用同一共享界面和 web-v1 传输实现；Android 读写原库，Windows 用 DPAPI 本机存储，PWA 使用 IndexedDB + Web Crypto 加密。
- 原生平台保留本机离线管理入口和已有 LAN 兼容模式。Windows 共享宿主依赖 Microsoft WebView2 Runtime，缺失时给出安装入口和原生本机 / LAN 入口。
- 不向服务器上传整个剪贴板库。接收已核对设备的文字后保存到对应设备板块；文件仍需确认接收并主动保存，文件内容不进入文字剪贴板库。
- 版本统一为 0.6.0；原版 Android versionCode 从 11 增至 12。旧 Share 预览包与原版包名不同，需明确安装 / 迁移说明，不能声称二者数据可跨沙箱自动读取。

## 连接与边界

新版本三端使用相同网页会话协议互通，现有 WebRTC / 小主机加密中继保留。手机悬浮球属于平台能力；PWA 不提供系统悬浮窗或静默后台剪贴板读取。蓝牙 / Wi-Fi Direct 本轮不新增为已发布功能。设备来源标识用于分组，不等于持久可信设备授权；设备信任和自动重连另行实施。

原生桥只对 https://clip.wmy-cloud.cn 的受信主页面开放，限制消息大小与操作，禁用任意文件路径 / 任意命令 / 通用主机对象。文件由系统选择器选择，保存使用临时文件和大小边界。剪贴板库采用版本比对写入，避免悬浮球与共享页面并发写入丢记录。

## 验收

- 旧版无来源记录、分类、置顶、备份兼容；更新后原库可读，坏库不得被空库覆盖。
- 两台同名设备以 ID 区分；重命名不拆分历史；相同文字来自不同设备分别保留。
- PWA 与两种宿主共用实际加密文本 / 文件传输测试；文件校验、发送回执、取消与限速继续有效。
- 三端版本、共享 UI、能力声明和安装包身份检查；Android 11 启动 / 桥权限测试，Windows 交叉编译。
- 未获得设备测试窗口前不使用手机 ADB，也不扫描或改动测力设备有线 LAN。真实 Win10/11 / iPad Safari 验收独立标注。
