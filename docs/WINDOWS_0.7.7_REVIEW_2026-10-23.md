# Windows 0.7.7 / build 22 修订与验收

本轮根据用户实机反馈修复 Windows 0.7.6 候选。文件页以此前确认的 `floatclip-file-shelf.html` 详细列表为视觉依据；不要重新改成另一种文件页。主程序仍为 WPF + WPF UI 4.3.0，保留当前同步和授权宿主。

## 已落实

- 顶栏整个空白区域可拖动，按钮区域正常响应点击；窗口固定状态使用同一钉子的实心/空心两态。
- 搜索框去除嵌套 TextBox 模板的残缺下划线，焦点只绘制外层完整边界。
- 左右滑动的固定、置顶、删除改成与卡片等高的连续操作区，不再出现悬在空白处的小按钮。
- 页面切换保持用户窗口宽度。文件页恢复“共享文件”标题、带上下分隔线的工具栏、蓝色下载主按钮、预览/另存为/转发/属性，低频选项收入“更多”。
- 文件列表采用与确认稿一致的实心/虚线类型图标、约 50 DIP 行高、左对齐列头。中等宽度调整各列占比，极窄窗口才水平滚动；不靠自动放大窗口显示信息。
- 底部只显示“文件数 | 已选择数量”，移除重复的大小/本机状态和长解释。操作结果短暂显示后消失。无传输时隐藏活动区，有活动时底部固定高度显示，取消 Expander 动画和高频整页重绘。
- 图片、PDF 第一页和文字文件有非模态原生预览。可执行文件的“预览”只显示图标与元信息，不启动程序。Office 正文暂由用户显式选择默认应用打开。
- 转发目前是发送到已连接的局域网设备；Windows 系统跨应用分享尚未实现。另存为可选择位置并重命名；远端文件先确认目标位置，再执行下载。深色下禁用的下载按钮使用可读的次要文字颜色。
- 设备页压缩为标题和常驻总开关、紧凑设备行、常驻设备开关和低频菜单；添加和高级选项折叠。新增重新连接入口。

## 蓝牙故障的实际排查

使用现有授权和个人手机，未重置配对或历史。Windows 的共享、发送、接收、应用以及自动连接开关均为开启。手机后台采集设置开启，但 ADB 采集辅助连接为断开，计数为零。

启动本轮调试客户端后，实际蓝牙 HELLO 双方通过；电脑新复制的文字发出 CLIP 并收到手机 ACK。恢复项目已有的 `activate-adb-clipboard.sh` 后，手机诊断为采集辅助已连接。通过已有 `AdbClipboardHelper --self-test-copy` 写入 QA 标记，Windows 收到 CLIP、发出 ACK，并验证该标记已自动写入 Windows 系统剪贴板。记录仅保留类型、计数和布尔结果，不保存正文或配对密钥。

这说明当前会话双向链路已恢复。当前 ADB 采集方案在手机重启后仍需重新激活辅助；不能将本次恢复描述为已解决所有重启/后台限制。手机包未更换，仍是此前 0.7.6 候选。

Windows 额外将“传输连接存在”和“同步握手完成”分开：收到有效 HELLO 后才显示同步就绪，握手超时后重连；诊断日志不含剪贴板正文、凭据、文件名或设备标识。日志位于本机 Host 的 `sync-diagnostics.jsonl`，不会随 Git 上传。

## 验证

- 原生 DesktopChecks 104 项通过，包含顶栏热区、实心/空心钉子、搜索模板、文件页宽度、工具栏、计数分隔和实际宿主 FCP3/FCP4 双向传输/ACK/重连。
- 完整桌面交互预览回归通过：五页导航、不随页面改宽、列排序、多选、显式下载、取消/重试、预览、滑动、保护清除、常驻开关、主题、320/520/1024 宽度。
- 截图和本轮 JSON 证据保存在 `analysis/desktop-checks`；文档目录只复制合成样本截图，不复制用户上传截图或用户数据。
- 线上更新清单未切换，D:\FloatClip 的原安装文件未被覆盖。本轮为修订试用包，非正式发版。
- 公共发布清单仍为 0.7.1。`updates/development-versions.json` 独立记录 Windows 0.7.7 / Android 0.7.6 开发候选，契约检查同时核对源码版本、构建号、发布元数据和单一原生宿主，避免把未发布的候选写入公共更新清单。
