# Windows build44 剪贴板恢复和加载

- 继续使用原有 Windows 用户级 DPAPI 索引和附件格式。加密恢复副本放在 `%LOCALAPPDATA%\FloatClipRecovery`，包含索引、设备 ID 和索引引用的原图，磁盘缩略图可再生成。
- 合并短时间内的保存，先写附件，最后原子替换恢复索引。索引丢失时验证副本和原图，恢复本机身份。只清理明确移除且已无引用的附件。
- 历史按页呈现。隐藏时释放已渲染卡片，缩略图内存预算降到 3 MiB，再次显示先复用内存和磁盘缩略图。
- 恢复范围为最后一次成功写入的副本。整个用户配置文件或磁盘丢失需要独立备份。

## 验收

- Windows x64 实机通过 107 项数据、48 项更新和 244 项 WPF 隔离检查。整目录丢失、恢复身份、附件丢失、主动清除及副本损坏均覆盖。
- 同机 80 张合成图对照中，收起后的解码缩略图占用从 14.1 MiB 降到 2.9 MiB。一次缓存和恢复副本写入结束后的首开采样从 405 ms 降到 359 ms。重开 build44 的首屏同步生成 12 行，中位耗时约 96 ms。该隔离环境中 build42 的重开未获得焦点，首屏为 0 行，耗时不可直接比较。
- 短时测试的进程工作集随运行波动，整进程长期挂机内存尚无可复现的降幅。
- 继续使用现有主题、控件和交互状态。WPF 回归覆盖搜索、清除、置顶、固定、预览与隔离同步。跨屏、各物理 DPI 和长期挂机留待实机连续使用验证。
