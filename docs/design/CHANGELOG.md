# 设计系统变更记录

## 2026-10-23：从 0.7.7 WPF 基线收敛

### 实施前差异

- WPF UI 4.3.0 已提供基础模板，但页面覆盖了大量局部颜色/圆角/字号，悬浮反馈不一致。
- Light、Dark、Tokyo Night 有三份硬编码配色；字体、菜单和禁用状态缺少统一语义资源。
- 卡片缩放和滑动动画时长各自声明，缺少应用层“减少动画”。
- 视图主要以 C# 命令式创建，查询/清除逻辑与具体控件混在一起，尚未全面 MVVM。
- 材质仅做圆角和深色标题栏处理，Mica/Acrylic 的特殊悬浮窗验收未完成。
- 原回归覆盖功能与截图，未完成四档真实系统 DPI/跨屏交互验收。

### 本轮最小方案

先统一 XAML 设计资源、Light/Tokyo Night、基础控件状态、卡片反馈和 Motion Tokens；将剪贴板查询与清除迁入 ViewModel/服务，搜索视图迁入 XAML。保留宿主及数据格式。材质先做能力评估和纯色回退，未验收的悬浮窗口不启用系统材质。后续逐页迁出剩余命令式视图，不能把这一步描述为全面 MVVM 完成。

### 第一轮结果

共享 Tokens / Light / Tokyo Night / 基础状态已落地；XAML 搜索与 CommunityToolkit MVVM 查询/清除落地。菜单错误引用修复，隔离验收不再吞异常。Release 和自包含打包成功，146 项桌面 + 33 项更新检查通过，隐藏界面异常 0。正文、次要、禁用和主按钮状态文字的配色对比度均达到 4.5:1。

完整证据范围及未验收内容见 [本轮 WPF 验收记录](../WINDOWS_WPF_DESIGN_077_2026-10-23.md)。真实系统当前为 150%，四档离屏输出不能等同四档实机验收；Mica/Acrylic 不启用；全部页面 MVVM、字符图标迁移和真实设备回归未完成。
