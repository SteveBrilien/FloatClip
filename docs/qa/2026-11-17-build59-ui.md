# FloatClip Android build59 — update sheet and file glyphs

## Fixed

- Update result surfaces keep the title and action row outside a bounded scrolling body. Long release notes can scroll independently, so Close and Download/Install stay reachable on the Android 11 phone.
- The file shelf no longer collapses every non-image file to the generic document icon. It maps common image, PDF, video, audio, archive, spreadsheet, presentation, text, source-code, application/package and generic-document extensions to distinct Fluent-style glyphs.
- Unknown extensions still use the generic document glyph rather than guessing a type.

## Verification

- Robolectric covers the long update-body hierarchy and representative file-extension mappings.
- Full app assemble and unit-test validation is required after the build-number bump.
- Device ADB is currently offline, so OEM rendering/touch acceptance on the vivo Android 11 phone remains pending. No app data is cleared or migrated by this change.
